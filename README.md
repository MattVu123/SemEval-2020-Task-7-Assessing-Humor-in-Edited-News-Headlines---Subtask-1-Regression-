# AIT 526 Final Project

**SemEval-2020 Task 7: Assessing Humor in Edited News Headlines - Subtask 1 (Regression)** 
---

-	Modified Python code (tensorflow, transformers, pandas) and experimented with four ALBERT transformer models with different configurations to predict funniness ratings of news headlines  
-	Best ALBERT model configuration used the Adam optimizer and a constant learning rate decay factor of 1e-8 to achieve a 0.5510 test set RMSE and would have ranked 22nd among the 48 official submissions  
-	The project presents new avenues for research concerning AI humor detection  
-   The Jupyter Notebook file titled "ait526_final_project_code2.ipynb" contains the code to train and evaluate all four ALBERT models.  The file also contains all the code for the project.
